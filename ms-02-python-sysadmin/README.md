# Phase 2: Python, administration, network

`ms-02-python-sysadmin` · school milestone 4 · 3 sub-modules, 2 written · 16 exercises

The school's milestone 4: the Python piscine, born2beroot and netpractice. Python is what L2, the measured inference server of the next phase, is built in. A machine administered by hand and a network read address by address prepare the servers and clusters of the infrastructure phases.

**Skills this phase builds**

- Python written unaided, from the basics to classes
- A Linux server installed, encrypted and hardened by hand
- IP routing and subnetting solved without tools

**Done when.** The campus intra validates the Python piscine, Born2beroot and NetPractice.

| Sub-module | Layer | What it covers | Where the work is |
|---|---|---|---|
| `t42-01-piscine-python` | imposed | Pass the eleven modules of the 2026 Python piscine, from functions to validated models, within each subject's scope: the exact names, the authorized functions, flake8, type hints checked by mypy, and the behaviour each requirement describes | 42 subject, not published · 11 exercises |
| `sh-01-b2br` | imposed | Administer a hardened machine, from encrypted partitioning to password policy, and be able to defend every choice: the subject's configuration files handed in and read, and the monitoring script run against command doubles | 42 subject, not published · 5 exercises |
| `sh-02-netpractice` | imposed | Split a network into subnets that satisfy a subject's constraints, and diagnose a configuration that does not route by naming the cause | 42 subject, not published |

Rows follow the order of the work; work done alongside the sequence comes last. Every English sentence on this page is translated from the curriculum's French and stored with a fingerprint of its source, so a changed source stops the page from being rebuilt.
